# อังกะลุงมือถือ · Mobile Angklung

แอปพลิเคชั่นเพื่อการศึกษาเท่านั้น — พัฒนาโดย **นายเจษฎา บุญญาภิชาติกาล**
โรงเรียนบดินทรเดชา (สิงห์ สิงหเสนี) สมุทรปราการ

🎋 เล่นได้ที่: https://boonyapichattigan-cmd.github.io/angklung/

- อังกะลุง 14 เสียง (เล่นคนเดียว) และเล่นเป็นวง (เลือก 2 ตัว)
- เสียงอังกะลุงจริง ตั้งตามความถี่เสียงไทย · เลือกคีย์สากลได้
- กลองแขก–ฉิ่ง หน้าทับต่าง ๆ ปรับความเร็วได้
- ฝึกบรรเลงเพลง และฝึกซ้อมตามจังหวะพร้อมนับคะแนน
- ติดตั้งบนหน้าจอโทรศัพท์ได้ (iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม · Android: Chrome → ⋮ → ติดตั้งแอป)
