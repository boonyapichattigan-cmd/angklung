อังกะลุงดิจิทัล — ไฟล์เว็บแอป (ติดตั้งบนหน้าจอโทรศัพท์ได้)
พัฒนาโดย นายเจษฎา บุญญาภิชาติกาล

ไฟล์ในโฟลเดอร์นี้ (ต้องอัปโหลดไปด้วยกันทั้งหมด)
  index.html              ตัวแอป
  manifest.webmanifest    ข้อมูลแอป (ชื่อ ไอคอน สี) ให้ติดตั้งบนหน้าจอได้
  sw.js                   ให้แอปเปิดได้แม้ไม่มีอินเทอร์เน็ต
  icon-*.png              ไอคอนแอป

ความต่างจากลิงก์ Claude เดิม
  - มีลิงก์เป็นของตัวเอง ไม่มีแถบ Claude / "Sign in" ด้านบน
  - ลงชื่อและส่งแบบประเมินแล้ว บันทึกลง Google Form เงียบ ๆ เบื้องหลัง ไม่เด้งหน้า Google Form
  - กด "เพิ่มไปยังหน้าจอโฮม" แล้วเปิดเต็มจอเหมือนแอปทั่วไป
  - เปิดซ้ำได้แม้ไม่มีอินเทอร์เน็ต (ครั้งแรกต้องออนไลน์)

------------------------------------------------------------
วิธีที่ 1: Netlify (ง่ายที่สุด ฟรี ลากวางโฟลเดอร์)
------------------------------------------------------------
1. ไปที่ https://app.netlify.com/signup สมัครด้วยบัญชี Google (ฟรี)
2. ไปที่ https://app.netlify.com/drop
3. ลากโฟลเดอร์ทั้งโฟลเดอร์ (ที่แตกไฟล์ zip แล้ว) วางลงในกรอบ
4. รอสักครู่ จะได้ลิงก์ เช่น https://xxxx.netlify.app
5. เปลี่ยนชื่อลิงก์ให้จำง่าย: Site configuration → Change site name
   เช่น angklung-bodin → https://angklung-bodin.netlify.app
6. อัปเดตแอปครั้งต่อไป: เข้าเว็บไซต์นั้น → Deploys → ลากโฟลเดอร์ใหม่วางทับ

------------------------------------------------------------
วิธีที่ 2: GitHub Pages (ฟรี)
------------------------------------------------------------
1. สมัคร https://github.com แล้วสร้าง Repository ใหม่ (Public) เช่น angklung
2. Add file → Upload files → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ → Commit changes
3. Settings → Pages → Branch: main / (root) → Save
4. รอ 1–2 นาที จะได้ลิงก์ https://ชื่อผู้ใช้.github.io/angklung/

------------------------------------------------------------
ติดตั้งบนโทรศัพท์ (บอกนักเรียน)
------------------------------------------------------------
  iPhone / iPad : เปิดลิงก์ใน Safari → ปุ่มแชร์ ⬆️ → "เพิ่มไปยังหน้าจอโฮม"
  Android       : เปิดลิงก์ใน Chrome → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
  ถ้าเปิดจาก LINE ให้กด ⋯ → "เปิดในเบราว์เซอร์" ก่อน แล้วค่อยติดตั้ง

หมายเหตุ
  - ต้องเป็นลิงก์ https (Netlify และ GitHub Pages เป็น https ให้อยู่แล้ว)
  - ข้อมูลการลงชื่อยังไปที่ Google Form / Google Sheet เดิมของคุณครู
